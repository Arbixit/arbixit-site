2. Vad villkoren omfattar

Villkoren gäller webbplatsen www.arbixit.se och de Arbixit-appar du fått åtkomst till, däribland Arbixit Task och dess koppling till Microsoft 365.

Har din organisation ett separat skriftligt avtal med oss – till exempel ett tjänsteavtal eller ett personuppgiftsbiträdesavtal – gäller det avtalet före dessa villkor vid motstridighet.

Vi får stänga av åtkomst omedelbart vid missbruk som riskerar tjänstens säkerhet eller drift, och underrättar dig då så snart det är möjligt.

5. Ditt innehåll och dina uppgifter

Din organisation äger sitt innehåll. Vi behandlar det endast för att leverera tjänsten, enligt integritetspolicyn. Personuppgifter som din organisation lägger in behandlar vi som personuppgiftsbiträde, på din organisations instruktion.

Du ansvarar för att du har rätt att lägga in det innehåll du lägger in – särskilt vid brevlådekopplingen i avsnitt 6, där e-post kan innehålla uppgifter om tredje part.

6. Microsoft 365-kopplingen

Arbixit Task kan kopplas till en enskild delad brevlåda i din organisations Microsoft 365, så att inkommande e-post blir ärenden i appen och svar kan skickas från brevlådan.

  • Kopplingen aktiveras genom att en administratör i din organisation godkänner den. Ingen enskild användare loggar in mot Microsoft via appen.
  • Åtkomsten avgränsas i din tenant med Exchange Application RBAC till exakt den brevlåda du pekar ut – appen kommer inte åt andra brevlådor, kalendrar eller filer.
  • Din administratör kan när som helst återkalla åtkomsten genom att ta bort rolltilldelningen eller tjänstens huvudobjekt i Microsoft Entra. Kopplingen upphör då omedelbart.
  • Vad som hämtas, lagras och gallras beskrivs i integritetspolicyn.

Microsoft 365 är din organisations egen tjänst. Vi ansvarar inte för dess tillgänglighet eller för ändringar Microsoft gör i sina gränssnitt.

7. AI-funktioner

Vissa appar har frivilliga AI-funktioner, till exempel sammanfattning av inkommande e-post och förslag på svar eller uppgifter.

  • Funktionerna är avstängda tills din organisation slår på dem.
  • Är de påslagna skickas berört innehåll till vår AI-leverantör för bearbetning. Se integritetspolicyn för vilka leverantörer det gäller.
  • Förslag från AI är just förslag. Ingenting skickas eller verkställs utan att en människa godkänner det.
  • AI-genererat innehåll kan bli fel. Du ansvarar för att granska det innan du använder det.

Vi arbetar för hög tillgänglighet men lämnar ingen garanti om inte annat avtalats skriftligt. Planerat underhåll aviseras i förväg när det går. Support lämnas i den omfattning som följer av din organisations avtal.

Tjänsterna tillhandahålls i befintligt skick. Vi ansvarar inte för indirekt skada, utebliven vinst eller förlust av data utöver vad som följer av tvingande lag. Vårt sammanlagda ansvar är begränsat till vad din organisation betalat för tjänsten under de tolv månader som föregick den händelse som orsakade skadan.

Begränsningen gäller inte vid uppsåt eller grov vårdslöshet.

11. Ändringar av villkoren

Vi kan behöva ändra villkoren, till exempel när tjänsterna utvecklas. Väsentliga ändringar aviseras minst 30 dagar i förväg via e-post eller i appen. Fortsatt användning efter att ändringen trätt i kraft innebär att du godtar den.

12. Uppsägning och avslut

Din organisation kan när som helst sluta använda tjänsten enligt sitt avtal. Vid avslut stänger vi åtkomsten och raderar eller återlämnar er data enligt integritetspolicyn. Brevlådekopplingen ska dessutom återkallas i er egen Microsoft 365-miljö enligt avsnitt 6.
